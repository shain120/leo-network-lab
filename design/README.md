# 原生桌面設計稿 01

狀態：視覺提案，待使用者確認。PNG 是靜態設計稿，不是正在執行的 Qt application；畫面節點、鏈路、覆蓋範圍均為示意，非實測、非軌道模型輸出。本階段不操作容器、不執行測試／linter、不提交 Git。

## 交付

- desktop-workspace.png：網路與換手工作台。
- desktop-security.png：安全驗證工作台。
- render_desktop.py：以 Pillow 重現設計圖；使用本機 Noto CJK 字型，無網路依賴。

## 視覺與佈局

以 Operate（操作工作台）為主要版型，原生視窗＋選單列，不使用 HTML／WebView。深灰藍背景、薄荷綠主操作、琥珀色草稿／警示。正常、待執行、失敗與未知須同時有文字和圖形，不能只以色彩區分。

- 背景 #10171e；面板 #19232d；分隔 #334352。
- 文字 #e7eef3；次要文字 #a7b7c5；主色 #7fd9c2；警示 #efc57d。
- 使用 Noto Sans CJK 與等寬程式碼字型；實作需支援高 DPI 與字型縮放。
- 左側固定導航與元件庫，中央主要操作面，右側上下地圖／屬性；底部可調整高度的 AI／終端／事件／工具證據面板。
- 靜態提案保留既定單一佈局，不提供三個僅換色版本。設計自檢未見行銷 hero、假指標卡、漸層或裝飾陰影；字型、標籤與圖例以工作台閱讀為目標。

## 後續原生實作映射（尚未實作）

PySide6 / Qt：QMainWindow + QMenuBar；QSplitter / QDockWidget 管理工作區；QGraphicsView + QGraphicsScene 提供拓樸節點拖曳與可選鏈路；地圖使用獨立場景；底部 QTabWidget，終端需另接真正 PTY，不可用純文字欄冒充互動 shell。

GUI 使用一般使用者權限；需特權的 Containernet 操作維持獨立、受限制的後端邊界，不能以 root 啟動整個桌面。工具執行透過 worker 與 signal，不阻塞 UI。前端不得直接讀 Docker socket。

## 互動規則

1. 拖入元件／自然語言提案 → 共用草稿 → 檢視變更 → 一次確認 → 執行 → 真實讀回。
2. 拖曳拓樸只調整排版；地理位置在明確的地理設定中修改。
3. 選取節點同步高亮拓樸、地圖與屬性；候選鏈路不表示雙衛星同時連線。
4. 查詢免確認；使用者在節點終端按 Enter 即執行該手動命令。AI 變更仍先確認。
5. 模擬時間與 wall-clock 量測分開，未知結果顯示未知，不顯示零或通過。
6. 安全頁保留受控壅塞與恢復為既定展示。OPA 僅為政策引擎的候選示例，PKI/mTLS 為待確認整合選項，非指定平台已驗證採用的技術。
7. 多波束、ACM、隨機存取與安全模組需待指定平台接口確認，不一次全部承諾實作。
